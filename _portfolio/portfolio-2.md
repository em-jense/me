[can i try again?](https://openprocessing.org/sketch/2860578) 

This Tracery poem hasn't been polished yet, however, I did still want to include it in my portfolio as it was one of the first projects I was really proud of. It was my first journey into working with coding language, and the first more 'serious' or vulnerable pieces I made in class. The poem is ultimately quite simple, with just a single line of text. But this one line of text takes on new meaning with each iteration, meant to represent the kind of desperation we can sometimes feel with wanting so badly to try sometime again, even when we know it won't work out. It's about words unspoken but viscerally felt. The physical text effects also attempts mimic this, being almost literal passing thoughts that fill up the screen until it is all noise as they go by.
